# 倪海厦独特理论：眼诊断法

> **来源**: 倪海厦人纪系列之《黄帝内经》及临床心得
> **定位**: 通过观察眼睛诊断疾病
> **核心**: "五脏六腑之精气，皆上注于目"

---

## 一、眼诊理论基础

### 1.1 目与五脏的关系

**《黄帝内经》理论**:
- **目**: 五脏六腑精气汇聚之处
- **肝开窍于目**: 肝血充足则目能视
- **心主血脉**: 心血充足则目得养
- **脾主肌肉**: 眼睑属脾
- **肺主气**: 白睛属肺
- **肾藏精**: 瞳孔属肾

### 1.2 五轮学说

**五轮**: 将眼睛分为五个部分，对应五脏

| 轮名 | 部位 | 对应脏腑 | 病变表现 |
|------|------|----------|----------|
| **肉轮** | 眼睑（上下眼睑） | 脾 | 眼睑红肿→脾热 |
| **血轮** | 两眦（内外眼角） | 心 | 眼角红赤→心火 |
| **气轮** | 白睛（眼白） | 肺 | 白睛发黄→肺热 |
| **风轮** | 黑睛（角膜） | 肝 | 角膜生翳→肝火 |
| **水轮** | 瞳神（瞳孔） | 肾 | 瞳孔异常→肾虚 |

## 二、眼诊方法

### 2.1 整体观察

**眼神**:
- 目光有神：正气充足
- 目光无神：正气虚弱
- 目光呆滞：神志异常
- 目光闪烁：心中有鬼

**眼色**:
| 颜色 | 对应病证 |
|------|----------|
| 目赤 | 肝火、心火 |
| 目黄 | 湿热、黄疸 |
| 目青 | 肝风、寒证 |
| 目白 | 血虚、贫血 |
| 目黑 | 肾虚、瘀血 |

### 2.2 分部观察

**眼睑**:
- 眼睑浮肿：脾虚湿盛
- 眼睑下垂：脾气下陷
- 眼睑红肿：脾胃有热
- 眼睑跳动：肝风内动

**白睛**:
- 白睛红丝：肺热
- 白睛黄染：湿热
- 白睛蓝斑：虫积
- 白睛出血：肺热伤络

**瞳孔**:
- 瞳孔缩小：中毒、肝火
- 瞳孔散大：肾虚、危证
- 瞳孔不等：中风、脑病

## 三、常见病眼诊

### 3.1 全身疾病

| 疾病 | 眼诊表现 |
|------|----------|
| **高血压** | 目赤、眼压增高 |
| **糖尿病** | 白内障、眼底出血 |
| **肝病** | 目黄、巩膜黄染 |
| **肾病** | 眼睑浮肿、目下暗黑 |
| **贫血** | 睑结膜苍白 |
| **甲亢** | 眼球突出、目珠跳动 |

### 3.2 眼科疾病

| 疾病 | 症状 | 辨证 |
|------|------|------|
| **红眼病** | 目赤肿痛 | 肝火上炎 |
| **白内障** | 瞳孔发白 | 肝肾阴虚 |
| **青光眼** | 眼压增高 | 肝阳上亢 |
| **近视** | 视物模糊 | 肝血不足 |
| **夜盲** | 入夜视力下降 | 肝血亏虚 |

## 四、倪海厦眼诊特色

### 4.1 眼诊辨证要点

1. **先辨眼神**: 判断正气盛衰
2. **次辨五轮**: 定位病变脏腑
3. **再辨颜色**: 定性寒热虚实
4. **结合脉诊**: 综合判断

### 4.2 临床案例应用

**肝火上炎**:
- 眼诊：目赤、眼胀、角膜生翳
- 辨证：肝火亢盛
- 治疗：清肝泻火（龙胆泻肝汤）

**肝肾阴虚**:
- 眼诊：目涩、视物模糊、瞳孔散大
- 辨证：肝肾阴亏
- 治疗：滋补肝肾（杞菊地黄丸）

## 五、针灸治疗眼病

### 5.1 常用穴位

| 穴位 | 定位 | 主治 |
|------|------|------|
| **睛明** | 目内眦旁0.1寸 | 近视、红眼病 |
| **攒竹** | 眉头凹陷处 | 头痛、目赤 |
| **四白** | 瞳孔直下1寸 | 近视、面瘫 |
| **太阳** | 眉梢与目外眦之间 | 头痛、目疾 |
| **风池** | 枕骨下 | 头痛、目眩 |

### 5.2 配穴方案

**近视**: 睛明、攒竹、四白、太阳、风池
**红眼病**: 睛明、太阳（点刺出血）、合谷
**白内障**: 睛明、攒竹、肝俞、肾俞
**夜盲**: 睛明、肝俞、肾俞、足三里
