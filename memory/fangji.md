## 五、方剂配伍原则

### 5.1 君臣佐使

| 角色 | 定义 | 示例（桂枝汤） |
|------|------|--------------|
| **君药** | 主药，治疗主病 | 桂枝 |
| **臣药** | 辅药，辅助君药 | 芍药 |
| **佐药** | 佐助药，治疗兼症 | 生姜 |
| **使药** | 引经药，调和诸药 | 大枣、甘草 |

### 5.2 七情和合

| 配伍 | 含义 | 示例 |
|------|------|------|
| **单行** | 单味药 | 独参汤 |
| **相须** | 功效相似，协同作用 | 麻黄配桂枝 |
| **相使** | 一药为主，一药为辅 | 黄芪配当归 |
| **相畏** | 一药毒性被另一药抑制 | 半夏畏生姜 |
| **相杀** | 一药能杀另一药之毒 | 生姜杀半夏毒 |
| **相恶** | 一药减弱另一药功效 | 人参恶莱菔子 |
| **相反** | 两药合用产生毒性 | 甘草反甘遂 |

## 六、倪海厦独特方剂应用

### 6.1 常用加减

**桂枝汤加减**:
- 项背强几几：加葛根（桂枝加葛根汤）
- 喘家：加厚朴、杏仁（桂枝加厚朴杏子汤）
- 发汗后漏汗：加附子（桂枝加附子汤）
- 胸满：去芍药（桂枝去芍药汤）

**麻黄汤加减**:
- 项背强几几：加葛根（葛根汤）
- 表寒里热：加石膏（大青龙汤）
- 外寒内饮：加半夏、细辛、干姜、五味子（小青龙汤）

### 6.2 特殊用法

**附子使用**:
- 必须先煎30-60分钟
- 用量从6g开始，逐渐加量
- 口尝无麻感为度

**大黄使用**:
- 后下，煎5-10分钟
- 中病即止
- 炮制后泻下力减弱
