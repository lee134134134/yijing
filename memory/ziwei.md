### 1.2 安命宫与身宫

**传统法**: 由寅宫起正月，顺数至生月；再以生月宫起子时——逆数至生时为**命宫**，顺数至生时为**身宫**。

**公式**（支序: 子0 丑1 寅2 卯3 辰4 巳5 午6 未7 申8 酉9 戌10 亥11）:

```
命宫支序 = (2 + 农历月 − 1 − 时支序) mod 12
身宫支序 = (2 + 农历月 − 1 + 时支序) mod 12
```

锚点验证: 正月子时 → 命宫在寅 ✓；四月午时 → 命宫在亥 ✓。

## 二、安紫微星

**算法**: 设农历生日 d、局数 n（水2 木3 金4 土5 火6）。若 n 不整除 d，借最小数 b 使 n 整除 (d+b)；商 q=(d+b)/n。从寅宫起顺数 q 宫得基准位；**借数 b 为奇数则逆退 b 宫，b 为偶数则顺进 b 宫**，即紫微落宫。

### 3.2 天府定位

## 八、大限规则

- **起限岁数 = 五行局之数**: 水二局 2 岁、木三局 3 岁、金四局 4 岁、土五局 5 岁、火六局 6 岁（虚岁），每十年换一宫。
- **行进方向**: 阳男阴女**顺行**（命宫 → 父母宫方向）；阴男阳女**逆行**（命宫 → 兄弟宫方向）。
- 阳年干: 甲丙戊庚壬；阴年干: 乙丁己辛癸。

## 九、流年、流月、流日

| 层级 | 规则 |
|------|------|
| 流年 | 流年命宫 = 流年地支在本命盘的落宫；流年四化按**流年年干**查四化表；流年红鸾天喜按**流年地支**重安 |
| 流月（斗君法） | 由流年支宫起正月顺数至**生月**，再由该宫起子时逆数至**生时**，即当年正月斗君位；二月起正月宫顺行一位，余类推 |
| 流日 | 由流月宫起初一**顺行**，每十二日循环一周（初一、十三、廿五回同一宫） |
| 流时 | 由流日宫起子时顺行，一时辰一宫 |

## 十、桃花星系与感情应期分析要点

### 10.1 桃花星性质

| 星曜 | 别称 | 性质与感情含义 |
|------|------|----------------|
| 贪狼 | 正桃花 | 欲望、才艺、应酬交际，异性缘核心星 |
| 廉贞 | 次桃花（囚星） | 感情执着、艺术气质，落陷主感情纠葛 |
| 天姚 | 风流桃花 | 魅力、暧昧、异性缘旺，主浪漫际遇 |
| 红鸾 | 正缘星 | 婚喜、恋爱萌动，主正式姻缘信号 |
| 天喜 | 喜庆星 | 红鸾对宫呼应，婚庆添喜 |
| 咸池 | 桃花煞 | 肉欲型桃花，主情欲纠葛 |
| 沐浴 | 桃花煞 | 与主星同宫时显桃花性质 |
| 天刑 | 孤克星 | 自律孤高，能收敛桃花（制桃花之星） |

### 10.2 应期推断次第

1. **本命基调**: 夫妻宫三方四正的主星组合与桃花星分布定一生感情模式；命宫或夫妻宫见贪狼、廉贞、天姚者异性缘旺。
2. **大限定十年基调**: 大限夫妻宫吉星汇聚且桃花星庙旺 → 该十年感情活跃期。
3. **流年应期（择时核心）**:
   - 流年红鸾 / 天喜入本命命宫、夫妻宫、福德宫，或入流年命宫、流年夫妻宫 → 婚恋喜庆之年；
   - 流年贪狼、天姚所在宫被流年化禄引动，且该宫居夫妻宫三方四正 → 恋爱机会显现；
   - 流年化禄入夫妻宫（或其三方四正）→ 感情顺遂有进展；
   - 流年化忌入夫妻宫 → 波折阻碍，不宜强求。
4. **流月细化**: 流月命宫叠红鸾、天喜、天姚，或流月化禄入夫妻宫 → 该月为具体应期窗口。
5. **反面信号**: 化忌 + 陀罗入夫妻宫主纠缠拖延；咸池、沐浴会天姚主烂桃花，需辨正缘与孽缘。
