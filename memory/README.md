> **说明**: 该知识库基于倪海厦 "天纪"、"人纪" 系列 PDF 资料整理而成，涵盖中医经典（黄帝内经、伤寒论、金匮要略、神农本草经、针灸）及命理风水（易经、紫微斗数、堪舆）。
> 
> **更新**: 新增 pdf/0612 目录中29本传统医学与命理学书籍的分类索引与核心纲要。
>
> **免责声明**: 该知识库仅供中医理论学习和文化研究参考，不能替代合格医师面诊、诊断、处方、用药或针灸操作。

## 使用指南

1. **咨询中医相关问题**: 优先查阅 [内经核心纲要](huangdi_neijing.md) 和 [伤寒论核心纲要](shanghanlun.md)
2. **查询具体方剂**: 查阅 [方剂核心概要](fangji.md) 或 [伤寒论核心纲要](shanghanlun.md)
3. **命理风水咨询**: 查阅 [天纪系列](tianjdao.md) 和 [命理八字系列](mingli_bazi.md)
4. **面相学咨询**: 查阅 [面相学系列](mianxiang.md)
5. **养生功法**: 查阅 [养生功法系列](yangsheng.md)
6. **了解倪海厦独特观点**: 查阅 [阴实理论](yinshi.md) 和 [药性气象学](yaoxing.md)
