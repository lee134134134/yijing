# 倪海厦医案核心概要

> **来源**: 倪海厦先生医案集
> **定位**: 临床应用实例，经方实战指南
> **核心**: "辨证论治，方证对应"

---

## 一、医案概览

### 1.1 倪海厦医案特点

1. **案例完整**: 从初诊到痊愈的全过程
2. **疗效显著**: 尤擅治疗重症、疑难杂症
3. **中西对照**: 结合西医检查指标
4. **经方为主**: 严格遵循经方原方原量

### 1.2 医案分类

| 类别 | 代表案例 | 特点 |
|------|----------|------|
| **内科杂病** | 感冒、咳嗽、胃病 | 常见病经方治疗 |
| **心血管疾病** | 高血压、心脏病 | 温阳利水 |
| **癌症肿瘤** | 肝癌、肺癌、胃癌 | 阴实理论 |
| **自身免疫** | 类风湿、红斑狼疮 | 清热解毒 |
| **妇科男科** | 不孕、阳痿 | 调理冲任 |
| **儿科** | 小儿感冒、积食 | 轻剂取效 |

## 二、典型案例分析

### 2.1 感冒发热案例

**案例一：太阳中风**

**初诊日期**: 2008年3月11日
**患者**: 女性，35岁
**主诉**: 发热，汗出，恶风，头痛
**问诊**:
- 有汗，恶风
- 头痛，项强
- 脉浮缓

**辨证**: 太阳中风
**处方**: 桂枝汤
**组成**: 桂枝9g，芍药9g，生姜9g，大枣12枚，甘草6g
**用法**: 水煎服，温服取汗
**结果**: 一剂汗出热退

## 三、医案分析要点

### 3.1 辨证要点

1. **望诊**: 面色、舌象
2. **闻诊**: 声音、气味
3. **问诊**: 十问（寒热、汗、头身、便、饮食、胸腹、耳目、睡眠、情绪、妇科）
4. **切诊**: 脉象

### 3.2 处方要点

1. **方证对应**: 有是证，用是方
2. **原方原量**: 尽量使用原方
3. **因人制宜**: 根据体质调整
4. **中病即止**: 症状缓解即停药

### 3.3 疗效判断

1. **症状改善**: 主观症状减轻
2. **体征变化**: 客观体征好转
3. **舌脉变化**: 舌象脉象改善
4. **检查指标**: 现代医学检查
