# 倪海厦《金匮要略》核心纲要

> **来源**: 倪海厦人纪系列之《金匮要略》
> **定位**: 杂病辨证论治，经方应用宝典
> **核心**: "辨证求因，审因论治"

---

## 一、金匮要略概述

### 1.1 与伤寒论的区别

| 特点 | 伤寒论 | 金匮要略 |
|------|--------|----------|
| **侧重** | 外感病 | 内伤杂病 |
| **病位** | 六经 | 脏腑 |
| **病种** | 急性传染病 | 慢性杂病 |
| **方法** | 六经辨证 | 脏腑辨证 |

### 1.2 金匮要略结构

全书25篇，涵盖：
- 内科杂病
- 外科疾病
- 妇科疾病
- 急救方法
- 食疗养生

## 二、脏腑经络先后病篇

### 2.1 脏腑辨证纲要

**肝**:
- 肝气虚则恐，实则怒
- 肝病者，两胁下痛
- **主方**: 酸枣仁汤、龙胆泻肝汤

**心**:
- 心虚则悲不已，实则笑不休
- 心病者，胸中痛
- **主方**: 炙甘草汤、天王补心丹

**脾**:
- 脾虚则四肢不用，实则腹胀
- **主方**: 理中汤、四君子汤

**肺**:
- 肺气虚则鼻塞不利，实则喘咳
- **主方**: 麦门冬汤、葶苈大枣泻肺汤

**肾**:
- 肾虚则恐惧，实则胀
- **主方**: 肾气丸、真武汤

## 三、中风历节病篇

### 3.1 中风辨证

**中风病位**:
- 中经络：口眼歪斜，半身不遂
- 中脏腑：昏迷不醒，痰涎壅盛

**中风方证**:

| 方剂 | 证候 |
|------|------|
| **大续命汤** | 中风昏倒，不省人事 |
| **小续命汤** | 中风偏瘫，口眼歪斜 |
| **风引汤** | 中风痰热内闭 |
| **侯氏黑散** | 中风偏枯 |

### 3.2 历节病

**概念**: 类似于现代医学的类风湿性关节炎

**辨证**:
- 风湿历节：关节肿痛，游走不定
- 寒湿历节：关节剧痛，固定不移

**主方**: **桂枝芍药知母汤**

| **阴虚** | 五心烦热，盗汗颧红 | 六味地黄丸 |

## 五、肺痿肺痈咳嗽上气篇

### 5.1 肺痿

**概念**: 肺气萎弱，津液枯涸

**辨证**:
- 虚热肺痿：咳吐浊唾，津枯液涸
- **主方**: 麦门冬汤

### 5.2 肺痈

**概念**: 肺部化脓性感染

**分期**:
1. **初期**: 风热犯肺
2. **成痈期**: 热毒壅肺
3. **溃脓期**: 脓血吐出
4. **恢复期**: 气阴两虚

**主方**: **千金苇茎汤**

### 5.3 咳嗽上气

**概念**: 咳嗽气逆，类似哮喘

**方证**:

| 方剂 | 证候 |
|------|------|
| **射干麻黄汤** | 咳嗽上气，喉中水鸡声 |
| **皂荚丸** | 咳逆上气，时时吐浊 |
| **厚朴麻黄汤** | 咳而脉浮 |
| **泽漆汤** | 咳而脉沉 |
| **麦门冬汤** | 火逆上气，咽喉不利 |
| **葶苈大枣泻肺汤** | 肺痈，喘不得卧 |

## 十五、倪海厦独特见解

### 15.1 金匮要略学习要点

1. **抓主症**: 每个病篇都有提纲挈领的主症
2. **辨方证**: 方证对应，有是证用是方
3. **重视原方**: 尽量使用原方原量
4. **明病机**: 理解每个方剂的病机

### 15.2 杂病治疗原则

- **先表后里**
- **先实后虚**
- **急则治标，缓则治本**
- **扶正祛邪兼顾**

### 15.3 经方应用心得

- 经方治疗杂病，效如桴鼓
- 辨证准确，经方灵验
- 不轻改经方，尊重原意
