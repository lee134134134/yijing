# 倪海厦《地脉道》核心纲要

> **来源**: 倪海厦天纪系列之地脉道
> **定位**: 风水堪舆，地理方位
> **核心**: "天人合一，环境和谐"

---

## 一、风水基础

### 1.1 风水概念

**风水**: 研究环境与人的关系的学问
**核心**: 天人合一，人与环境和谐

### 1.2 阴阳五行

**阴阳**:
- 阳：天、男、刚、动、外、上、左、前
- 阴：地、女、柔、静、内、下、右、后

**五行**: 金、木、水、火、土

### 2.2 户型格局

**理想户型**:
- 方正：长方形或正方形
- 门不对门
- 窗不对窗
- 厨房在凶位
- 卧室在吉位

### 2.3 卧室风水

**床位**:
- 床头靠墙
- 床不可对门
- 床不可对窗
- 床不可在梁下

**颜色**:
- 主卧：温馨色调
- 儿童房：明亮色调
- 老人房：稳重色调

## 三、阴宅风水

### 3.1 墓地选择

**原则**:
- 背山面水
- 左青龙，右白虎
- 前朱雀，后玄武
- 藏风聚气

### 3.2 墓地禁忌

- 不可在路口
- 不可在水边
- 不可在高压线下
- 不可有恶形

---

## 四、办公室风水

### 4.1 办公桌方位

**理想方位**:
- 背靠实墙
- 面朝门口
- 左手边高，右手边低
- 前方开阔

### 4.2 办公室布局

**老板办公室**:
- 在办公区后方
- 面积较大
- 采光良好

**员工办公区**:
- 整齐有序
- 通风良好
- 光线充足

---

## 五、风水调整方法

### 5.1 外部环境调整

**水法**:
- 水为财，宜环抱不宜直冲
- 明堂开阔，藏风聚气
- 道路环抱，不宜直冲

**山法**:
- 靠山要实
- 左右护砂
- 前方案山

### 5.2 内部布局调整

**玄关**:
- 入门见玄关
- 遮挡煞气
- 引导气流

**客厅**:
- 明亮宽敞
- 沙发靠墙
- 主位在吉方

**厨房**:
- 炉灶背靠实墙
- 水火不相冲
- 冰箱不在炉灶对面

### 5.3 化煞方法

**常见煞气**:
| 煞气 | 表现 | 化解方法 |
|------|------|----------|
| **路冲** | 道路直冲门窗 | 设置屏风、植物 |
| **尖角煞** | 屋角直射 | 设置遮挡 |
| **天斩煞** | 两楼夹缝 | 设置凸镜 |
| **反弓煞** | 道路反弓 | 设置植物 |

## 六、倪海厦风水见解

### 6.1 风水核心

1. **藏风聚气**: 风水第一要义
2. **阴阳平衡**: 过阴过阳皆不宜
3. **形理兼备**: 形势与理气结合
4. **以人为本**: 风水服务于人

### 6.2 现代风水应用

- 高层住宅：注重内部布局
- 商业选址：注重外部环境
- 办公室布置：注重工作效率

### 6.3 风水与命运

倪海厦认为风水占命运的三分之一：
```
天命（1/3） + 人纪医学（1/3） + 地纪风水（1/3） > 命运
```
