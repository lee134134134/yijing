## 二、核心穴位详解

### 2.1 急救穴位

| 穴位 | 定位 | 主治 | 操作 |
|------|------|------|------|
| **人中** | 鼻柱下，沟中央 | 昏迷、休克、癫痫 | 向上斜刺0.3-0.5寸 |
| **百会** | 头顶正中 | 头痛、眩晕、脱肛 | 平刺0.5-0.8寸 |
| **涌泉** | 足底前1/3凹陷处 | 昏迷、中暑、癫痫 | 直刺0.5-1寸 |
| **十宣** | 十指尖端 | 昏迷、高热 | 点刺出血 |
| **内关** | 腕横纹上2寸 | 心绞痛、呕吐、晕车 | 直刺0.5-1寸 |
| **足三里** | 膝下3寸，胫骨外1横指 | 虚脱、休克、胃痛 | 直刺1-2寸 |

## 三、针刺手法

### 3.1 进针方法

| 方法 | 适用部位 | 操作要点 |
|------|----------|----------|
| **指切进针** | 短针 | 左手切按，右手持针 |
| **夹持进针** | 长针 | 两手夹持针身 |
| **提捏进针** | 皮肤浅薄处 | 提捏皮肤后进针 |
| **舒张进针** | 皮肤松弛处 | 舒展皮肤后进针 |

### 3.2 补泻手法

**基本补泻**:

| 手法 | 补法 | 泻法 |
|------|------|------|
| **捻转** | 左转（拇指向前） | 右转（食指向后） |
| **提插** | 重插轻提 | 轻插重提 |
| **迎随** | 随经而刺 | 迎经而刺 |
| **呼吸** | 呼气进针，吸气出针 | 吸气进针，呼气出针 |
| **开阖** | 出针后按穴 | 出针后不按穴 |

**烧山火（补法）**:
1. 进针至天部（浅层）
2. 紧按慢提九次
3. 进针至人部（中层）
4. 紧按慢提九次
5. 进针至地部（深层）
6. 紧按慢提九次
7. 退针至天部，留针

**透天凉（泻法）**:
1. 进针至地部（深层）
2. 紧提慢按六次
3. 退针至人部（中层）
4. 紧提慢按六次
5. 退针至天部（浅层）
6. 紧提慢按六次
7. 出针，不按穴

### 3.3 针刺深度与角度

| 部位 | 深度 | 角度 |
|------|------|------|
| 头部 | 0.3-0.8寸 | 平刺 |
| 面部 | 0.3-0.5寸 | 平刺 |
| 颈部 | 0.3-0.8寸 | 直刺或斜刺 |
| 胸部 | 0.3-0.5寸 | 平刺或斜刺 |
| 腹部 | 1-2寸 | 直刺 |
| 背部 | 0.5-1寸 | 斜刺 |
| 四肢 | 1-2寸 | 直刺 |

## 五、特殊针法

### 5.1 艾灸

**适应症**:
- 虚寒证
- 慢性病
- 保健养生

**常用方法**:
- 温和灸：距离皮肤2-3cm
- 雀啄灸：上下移动
- 回旋灸：左右移动
- 直接灸：艾炷直接放置皮肤

**常用穴位**:
- 足三里：保健要穴
- 关元：补益元气
- 气海：益气健脾
- 神阙：温阳救逆

### 5.2 拔罐

**适应症**:
- 风寒湿痹
- 腰背疼痛
- 感冒发热

**常用部位**:
- 背部膀胱经
- 肩部
- 腰部

### 5.3 耳针

**耳穴分布**:
- 耳垂：面部、五官
- 耳舟：上肢
- 对耳轮：躯干、下肢
- 耳甲：内脏

**常用耳穴**:
- 神门：镇静安神
- 交感：调节自主神经
- 肾上腺：抗炎、抗休克
- 皮质下：调节大脑皮层

## 六、倪海厦独特见解

### 6.1 针灸治疗原则

1. **经络辨证**: 根据经络循行和穴位特性辨证
2. **精准取穴**: 穴位定位准确
3. **手法到位**: 补泻手法正确
4. **因人制宜**: 根据体质调整

### 6.2 北派针刺手法

倪海厦采用明朝杨继洲《针灸大成》手法：
- 强调手法的重要性
- 重视补泻操作
- 注重针刺深度和角度

### 6.3 经方与针灸结合

- 针灸治疗无效时，考虑用经方
- 经方治疗同时配合针灸
- 针药并用，提高疗效

### 6.4 针灸禁忌

**禁针部位**:
- 重要脏器部位
- 大血管部位
- 孕妇腹部、腰骶部

**禁灸部位**:
- 面部
- 乳头
- 阴部
- 大血管处
