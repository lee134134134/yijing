### 1.2 简介

中国古代房中养生是中国传统文化中的一个重要组成部分，历史悠久，源远流长。在古代，房中术被视为一种养生方法，与导引、吐纳、服气等修炼方法并列。

主要内容包括：
- **节制原则**：强调有所节制，不过不纵
- **房中禁忌**：时间、地点、身体状况等禁忌
- **养生方法**：如还精补脑、采阴补阳等
- **医药辅助**：如服用相关药物以辅助养生

### 2.2 八部金刚功简介

**八部金刚功**是道家养生的重要功法，由张至顺道长（米晶子）所传。此功法属于外功，通过八个动作来调理全身经络、强身健体。

八部金刚功的八个动作：
1. **双手插顶利三焦**
2. **左右开弓似射雕**
3. **调理脾胃须单举**
4. **五劳七伤往后瞧**
5. **摇头摆尾去心火**
6. **两手攀足固肾腰**
7. **攥拳怒目增力气**
8. **背后七颠百病消**

练习要点：
- 动作舒展大方，配合呼吸
- 意念集中，气沉丹田
- 由浅入深，循序渐进
- 持之以恒，方见效果

### 2.3 炁体源流简介

**《炁体源流》**是张至顺道长的重要著作，分为上下两册，主要内容包括：

- **道家经典辑录**：收录了道家重要的经典文献
- **内丹修炼心法**：道家内丹修炼的核心方法
- **养生经验总结**：张道长数十年的修炼经验
- **道医治病方法**：道医体系中的治病智慧

张至顺道长（1912-2015），道号"米晶子"，河南沈丘人，是全真龙门派第二十一代传人。他自幼家贫，17岁出家修道，一生坎坷，但精通道医、武术，尤擅养生。

### 2.4 米晶子济世良方简介

**《米晶子济世良方》**是张至顺道长收集整理的单方验方集，主要特点：

- **简便效廉**：所用药物多为常见草药
- **疗效确切**：多为经过验证的验方
- **分类明确**：按病证分类便于查阅
- **用量精确**：详细记录药物用量

- **经方应用**：对经方的理解和应用有独特见解

**主要内容**：
- 二十四节气与疾病的关系
- 阴阳升降的生理病理

## 四、道医体系概览

### 4.1 道医的特点

**道医**是中国传统医学的重要流派，与中医学有深厚的渊源。

| 特征 | 说明 |
|------|------|
| **整体观** | 强调天、地、人三才合一 |
| **预防为主** | 重视未病先防、既病防变 |
| **形神兼养** | 既重视身体，也重视精神 |
| **内外兼修** | 内服药物，外炼功法 |
| **简便效廉** | 多用简单有效的方法 |

### 4.2 道医与中医的关系

道医与中医同源而异流，有共同的经典基础：
- 共同源头：《黄帝内经》、《神农本草经》等
- 共同理论：阴阳五行、脏腑经络等
- 差异特点：道医更强调修炼和养生功法
